### 1. Technology stack and languages
    Frontend - React (in Typescript - Javascript with type security)
    Backend - NodeJS (using ExpressJs library) (in Typescript - Javascript with type security)

### 2. run the following commands for running the application
    - ensure nodejs is installed in your system
    - go to the project directory
    - npm run setup (to install all the node modules)
    - npm run dev (to start the server and client)
    - Go on this link to open the client : http://localhost:5173/  

### 3. If the above method does not work
    - staying in root directory do 'npm i'
    - go to server directory, do 'npm i' and run 'npx tsc && node dist/app.js' 
    - go to client directory, do 'npm i' and run 'npm run dev'
    - Go on this link to open the client : http://localhost:5173/
